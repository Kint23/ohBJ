# 部署指南（评审必须能点开链接，这一步不能省）

> 截止前请务必完成：**部署 → 拿到网址 → 把网址加进 AK 的 Referer 白名单 → 用无痕窗口验证**。

---

## 一、方式 A：GitHub Pages（推荐，已配好自动化）

仓库里已放好 `.github/workflows/pages.yml`，**推送后自动部署**，无需手动操作。

### 1. 建仓库并推送

```powershell
# 先配一次 git 身份（本机还没配，不配会导致 commit 失败）
git config --global user.name "你的名字或 GitHub 用户名"
git config --global user.email "你的邮箱"

cd C:\Users\user\Music\ohbj
git init -b main
git add .
git commit -m "帝京寻踪 · 明代北京古今地图"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

> **仓库必须设为 Public**：免费账号的 GitHub Pages 只对公开仓库生效。古籍原文是公版文本，公开无版权问题，
> 反而能体现数据来源与可复现性。（若不想公开语料，把 `*.txt` 加进 `.gitignore` 即可。）
>
> 首次 `push` 会让你登录 GitHub：**不能用账号密码**，按弹窗选浏览器登录（Git Credential Manager），
> 或到 Settings → Developer settings → Personal access tokens 生成 token 当密码用。

### 2. 打开 Pages

仓库 → **Settings → Pages → Build and deployment → Source 选 `GitHub Actions`**。
下次 push（或手动 Run workflow）后，约 1 分钟得到网址：

```
https://<你的用户名>.github.io/<仓库名>/
```

### 3. ★ 把网址加进 AK 白名单（**漏了这步地图一定不显示**）

到 <https://lbsyun.baidu.com/apiconsole/key> → 编辑你的**浏览器端** AK → Referer 白名单改成：

```
*localhost*,*127.0.0.1*,*<你的用户名>.github.io*
```

> 用通配符包起来更稳。改完保存，可能需要几分钟生效。

### 4. 用**无痕窗口**验证

- [ ] 页面打开正常，三栏布局完整
- [ ] 地图底图出现、30 个标记可见
- [ ] 点一个标记 → 右侧出现原文/诗词/今译
- [ ] 「智能排线」点「生成 3 个方案」→ 出现 3 个方案
- [ ] 切「行程模式」→ 选出行方式 → 「生成路线」→ 出现真实里程
- [ ] 右下角「问问导游」→ 问「半天想逛寺庙，怎么走？」→ 出现 3 个方案

## 二、方式 B：Netlify Drop（最快，不用 git、不用 GitHub）

适合只想先拿到一个能点开的链接：

```powershell
# 生成一个只含演示必需文件的 dist/ 目录（自动排除 7MB 古籍原文）
cd C:\Users\user\Music\ohbj
Remove-Item -Recurse -Force dist -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path dist, dist\data | Out-Null
Copy-Item index.html dist\
Copy-Item -Recurse app dist\app
Copy-Item data\places.json, data\routes.json dist\data\
Copy-Item README.md dist\
Copy-Item -Recurse docs dist\docs -ErrorAction SilentlyContinue
```

然后打开 <https://app.netlify.com/drop>，把 **`dist` 文件夹**整个拖进去，几秒后得到 `https://xxxx.netlify.app`。

⚠️ 拿到链接后**立刻把这个域名加进 AK 的 Referer 白名单**，否则地图不显示。
（Netlify 免费域名可能变化，重部署后 URL 一般不变。）

## 三、方式 C：其他静态托管

本项目是**纯静态站点、无构建步骤**，根目录即站点根目录，可直接拖到：

- **Vercel / Netlify**：导入仓库，Framework 选 `Other`，Build Command 留空，Output Directory 填 `.`
- **对象存储**（OSS/COS/七牛）：上传 `index.html` + `app/` + `data/places.json` + `data/routes.json`
- **Cloudflare Pages**：同上

⚠️ 无论用哪种，都要：
1. 站点必须能通过 **HTTPS** 访问（部分浏览器限制混合内容）；
2. **把最终域名加进 AK 的 Referer 白名单**；
3. 必须是**目录形式**访问（`https://域名/` 或 `https://域名/子路径/`），
   本项目用的是相对路径（`app/app.js`、`data/places.json`），因此部署在**子路径下也能正常工作**。

## 四、踩坑记录（都已在代码里规避）

| 现象 | 原因 | 现状 |
|---|---|---|
| 弹窗「APP不存在，AK有误」并卡死整页 | 用了**服务端** AK；或 AK 为空时同步加载 JSAPI 触发阻塞 alert | 已修：AK 为空时**不发请求**，页面其余部分照常可用 |
| 地图空白、无报错 | Referer 白名单没含当前域名 | 见上面第 3 步 |
| 打开是空白页、控制台报 CORS | 直接双击 `index.html`（`file://` 协议） | 必须用 http(s) 访问 |
| 关闭导游面板后点不动地图 | `.gx{display:flex}` 覆盖了 `hidden` | 已修 |
| 路线显示 `NaN m` | BMapGL 的 `getDistance()` 返回 `"2.4公里"` 字符串 | 已修（带单位解析） |
